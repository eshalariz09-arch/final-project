# Simple Interest Calculator

## Description

A simple web-based calculator that calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (P × R × T) / 100

Where:

- P = Principal amount
- R = Rate of interest
- T = Time period

## Features

- Calculate simple interest
- Simple and user-friendly interface
- Easy to use

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Enter the principal amount.
2. Enter the rate of interest.
3. Enter the time period.
4. Click the Calculate button.
5. The calculated simple interest will be displayed.
